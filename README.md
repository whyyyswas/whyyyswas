| Aspect | Detail |
|---|---|
| **Stack** | Python, XGBoost, Tesseract OCR, Poppler, C |

| **Security** | Local document processing with structured data handling |
| **Impact** | Makes credit literacy accessible to first-time users via automated analysis |
